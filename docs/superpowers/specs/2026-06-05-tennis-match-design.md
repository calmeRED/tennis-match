# 网球比赛网页 - 设计规格说明

## 1. 项目概述

**项目名称：** tennis-match
**项目类型：** 静态网页（GitHub Pages 部署）
**核心功能：** 赛事预告与报名、冠军墙、数据查询
**设计风格：** 简约专业型（深蓝+白色、表格化布局）

---

## 2. 功能模块

### 2.1 赛事预告与报名

- 展示赛事基本信息（日期、地点、规模、组别）
- 报名方式：二维码 + 联系方式（微信/群链接）
- 数据来源：`events.csv`（手动管理，用户自行编辑上传）

**events.csv 字段：**
| 字段 | 说明 |
|------|------|
| 期次 | 赛事期号 |
| 名称 | 赛事名称 |
| 日期 | 比赛日期 |
| 地点 | 场地 |
| 规模 | 参赛人数 |
| 组别 | 比赛组别（动态，多个用分隔符） |
| 报名方式 | 描述报名途径 |
| 二维码链接 | 微信群二维码图片 URL |

### 2.2 冠军墙

- 网格卡片展示，按期次分区
- 每张卡片显示：选手姓名、冠军赛季、组别
- 点击卡片可查看该选手冠军之路（跳转至选手查询结果）

**数据来源：** 从 `matches.csv` 自动提取决赛胜者

### 2.3 数据查询

#### 单期数据查询
- 输入期次 → 显示该期所有比赛列表
- 展示字段：场次、比赛轮次、组别、选手A姓名、选手B姓名、比分、比赛日期、胜者

#### 选手历史查询
- 输入姓名 → 显示该选手历史战绩
- 展示字段：胜率、冠军数、亚军数、参赛期数、最近参赛

## 3. 数据结构

### 3.1 matches.csv（比赛数据 - 用户维护）

```
期次,场次,比赛轮次,组别,选手A姓名,选手B姓名,选手A比分,选手B比分,比赛日期
```

**字段说明：**
| 字段 | 说明 |
|------|------|
| 期次 | 赛事期号 |
| 场次 | 比赛序号 |
| 比赛轮次 | 小组赛/淘汰赛/半决赛/决赛 |
| 组别 | 男单/女单/混双 等（动态） |
| 选手A姓名 | |
| 选手B姓名 | |
| 选手A比分 | |
| 选手B比分 | |
| 比赛日期 | YYYY-MM-DD 格式 |

### 3.2 players.csv（选手数据 - 自动生成）

```
选手姓名,性别,胜率,冠军数,亚军数,参赛期数,最近参赛
```

**字段说明：**
| 字段 | 说明 | 来源 |
|------|------|------|
| 选手姓名 | | 从 matches.csv 提取 |
| 性别 | 手动维护 | 用户维护 |
| 胜率 | 百分比 | 自动计算：(胜场数 / 总场数) × 100% |
| 冠军数 | 整数 | 自动遍历：统计该选手在决赛中胜出的次数 |
| 亚军数 | 整数 | 自动遍历：统计该选手在决赛中失败的次数 |
| 参赛期数 | 整数 | 自动遍历：统计该选手出现的期次去重数量 |
| 最近参赛 | 日期 | 自动取最大比赛日期 |

### 3.3 自动推断逻辑

- **胜者：** 比分高者自动标记为胜者（仅用于冠军墙展示）
- **冠军：** 决赛（比赛轮次=决赛）胜者为该组别冠军
- **亚军：** 决赛负者为该组别亚军

## 4. 自动化流程

### 4.1 GitHub Actions 工作流

```
用户上传 matches.csv 
    → Push 到 main 分支
    → GitHub Action 触发
    → 运行 csv_processor.py：
        1. 读取 matches.csv
        2. 自动推断「胜者」字段
        3. 生成/更新 players.csv
        4. 更新 events.csv（如需要）
    → 自动 commit 生成的 players.csv
    → 部署到 GitHub Pages
```

### 4.2 csv_processor.py 功能

1. 读取 `matches.csv`
2. 自动推断「胜者」字段（比分高者为胜）
3. 生成 `players.csv`（首次）或更新现有 `players.csv`（增量更新）
4. 输出日志

## 5. 技术方案

### 5.1 技术栈

- **前端：** HTML + CSS + JavaScript（纯静态，无框架）
- **后端处理：** Python（csv_processor.py，用于 GitHub Action）
- **部署：** GitHub Pages（推送即部署）

### 5.2 项目结构

```
tennis-match/
├── index.html          # 单页应用入口
├── css/
│   └── style.css      # 样式（简约专业型）
├── js/
│   ├── app.js         # 主逻辑、路由
│   ├── csv_parser.js  # CSV 解析与展示
│   └── ui.js          # UI 组件渲染
├── data/              # 数据目录（git 管理）
│   ├── matches.csv     # 比赛数据（用户维护）
│   ├── players.csv     # 选手数据（自动生成）
│   └── events.csv      # 赛事预告（用户维护）
├── scripts/
│   └── csv_processor.py # 数据处理脚本
├── .github/
│   └── workflows/
│       └── ci.yml     # GitHub Actions 配置
└── docs/
    └── specs/         # 设计文档
```

### 5.3 关键文件说明

| 文件 | 作用 |
|------|------|
| `index.html` | 单页应用，三个功能模块切换 |
| `csv_parser.js` | 读取 CSV、解析、转换为可用数据 |
| `app.js` | 页面逻辑、查询功能、渲染 |
| `csv_processor.py` | GitHub Action 调用，处理 CSV 自动生成 players.csv |
| `ci.yml` | GitHub Actions 工作流配置 |
